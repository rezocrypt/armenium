# 🇦🇲 Armenium

> **The first Armenian Darknet (TOR, I2P) Website**

**Armenium** is a small experimental project featuring harmless demonstration programs named after Armenian cities and villages.

Each "virus" is created for **educational, historical, and entertainment purposes** — they are not intended to damage systems or cause harm.

### 🦠 What's inside?

A collection of fictional / harmless viruses carrying names inspired by places across Armenia.

The idea is simple:

**Armenian places × computer viruses = Armenium**

### ⚠️ Disclaimer

These files are demonstrations and are **not intended to harm users, computers, or data**.

Use them only in safe environments and for educational purposes.
